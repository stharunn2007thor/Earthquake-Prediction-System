# Earthquake Prediction using Machine Learning

A Flask-based web application that predicts earthquake magnitude/risk using a trained machine learning model with data visualisation

## 🚀 Live Demo

 https://earthquake-prediction-system-1.onrender.com

## Features

- Predict earthquake outcomes
- Flask web interface
- Machine Learning model
- Easy to use

## Tech Stack

- Python
- Flask
- Scikit-learn
- Pandas
- Numpy
- Seaborn
- Matplotlib
- HTML/CSS

## Installation

```bash
git clone https://github.com/your-username/earthquake-prediction.git
cd earthquake-prediction
pip install -r requirements.txt
python app.py
```
